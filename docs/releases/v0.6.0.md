# BAO Toolkit v0.6.0: B20 Evidence & App Activity

Status: publication authorized on 2026-10-04; package publication and post-release verification pending.

## Release scope

BAO Toolkit v0.6.0 adds B20 token inspection and receipt-aware transaction replay,
an app activity dashboard, and a shared workspace for the developer tools.
The product site and repository use BAO Toolkit; npm imports retain the
`@base-attribution-os/*` scope and the CLI command remains `bao`.

- Inspect source-pinned B20 initialization evidence with `bao b20 inspect`.
- Replay an explicit transaction sample with `bao b20 replay`, retaining direct
  operation attribution, receipt comparisons, factory events, and unresolved rows.
- Validate artifacts offline or recheck their original block context over an
  explicitly configured RPC with `bao b20 verify`.
- Reproduce the synthetic missing-code/fixed-code transfer example and inspect
  two recorded reports covering eight public mainnet and Sepolia transactions.
- Explore app activity by Builder Code with indexed data and CSV/JSON imports.
  Activity, Evidence, Doctor, Proofs, B20, and Wallets share one workspace.
- Use the updated product site, documentation, canonical URLs, share cards,
  product answers, and Vercel Analytics.
- Update the Action HTTP dependency to undici 6.28.1 without changing Action inputs.

## Compatibility and evidence limits

Existing attribution commands, Proof Set v1, SDK adapters, scanner rules, and
Action inputs retain their contracts. The CLI gains B20 and its external viem
dependency; existing attribution-only core and adapters do not depend on B20.

B20 inspection and replay operate on declared samples and supported call scopes.
Offline checks validate internal consistency; they do not become fresh RPC
evidence. The before/after transfer receipts are synthetic. Recorded observations
establish evidence for eight selected transactions, not complete app coverage.

Controlled native B20 transfer comparison and an external integrator pilot remain
untested. Runtime qualification remains `not-qualified`, and application readiness
remains `not-tested`. This release publishes analysis tools and does not certify
B20 integration readiness. The historical Stack the Bag proof evidence remains
unchanged; no new Stack the Bag or external B20 pilot is claimed for this release.
